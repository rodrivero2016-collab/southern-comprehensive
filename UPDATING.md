# How to update the website

Everything lives in `~/Documents/southern-comprehensive`. Edit a file, then push. One minute later
it's live.

---

## The loop

```bash
cd ~/Documents/southern-comprehensive
```

Make your edits, then:

```bash
git add -A
git commit -m "Updated the phone number"
git push
```

That's it. GitHub rebuilds the site automatically.

**Always preview before you push:**

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` and click around. Press **Control-C** in Terminal to stop.

---

## ⚠️ The one thing that will bite you

The 14 HTML pages are **generated by `build.py`**. If you hand-edit `medicare.html` and later run
`python3 build.py`, your edit is erased.

Two safe ways to work — pick one and stick to it:

**Option A — Edit the HTML directly (simplest).** Fine for text changes. Just never run `build.py`
again. If you want to be safe about it, delete `build.py`.

**Option B — Edit `build.py`, then regenerate.** Required for anything that repeats across pages
(menu, footer, phone number). Run `python3 build.py` after editing.

For most day-to-day changes, Option A is what you want.

---

## What to edit for what

| You want to change | Edit this |
|---|---|
| Text on one page | That page's `.html` file |
| Phone, email, address, license | `build.py` (top of file), then regenerate — it appears on all 14 pages |
| Menu items or footer links | `build.py` — the `NAV` list and `footer()` function |
| Colors, fonts, spacing | `assets/css/styles.css` |
| Calculator math or rates | `assets/js/main.js` |
| The AI agents' instructions | `agent-tools/agents.js` |
| Agent Tools password | `agent-tools/index.html` — the `PASSWORD_HASH` line |
| Add a blog post | Copy any `.html` file, edit it, save into `blog/`, link it from `blog.html` |

## Common edits, step by step

### Replace a placeholder

Placeholders show as yellow highlighted text. Find them all:

```bash
grep -rn 'class="ph"' *.html | head -30
```

Open the file, find the `<span class="ph">[SOMETHING]</span>`, and replace the whole span —
including the tags — with your real text.

### Change the phone number everywhere

Open `build.py`, change line 7 (`PHONE_TXT`) and line 8 (`PHONE_HREF`), then:

```bash
python3 build.py
```

### Add a testimonial

Open `reviews.html`, copy an existing `<blockquote class="quote">` block, and edit the text and
attribution. Get written permission from the client first.

### Add Roosevelt's photo

Save the image as `assets/img/roosevelt.jpg`, then in `about.html` find the block containing
`PLACEHOLDER — team or founder photograph` and replace that entire `<div class="hero__photo">…</div>`
with:

```html
<img src="assets/img/roosevelt.jpg" alt="Roosevelt Brown Jr." style="border-radius:16px">
```

### Connect Calendly

Open `contact.html`, search for `CALENDLY`. Uncomment the embed block, paste your link, and delete
the placeholder button above it.

## If something breaks

Nothing is ever lost — every version is saved in Git.

**Undo everything since your last push:**

```bash
git checkout -- .
```

**See what you changed before committing:**

```bash
git status
git diff
```

**Roll the live site back to the previous version:**

```bash
git log --oneline
git revert HEAD
git push
```

## Before any Medicare-related change goes live

Anything mentioning plan benefits, costs, star ratings, or carrier names is **marketing** under CMS
rules and needs carrier or FMO review before it publishes. Run it through the Medicare Compliance
Officer in Agent Tools first — that's a good pre-check, not a substitute for the real review.
